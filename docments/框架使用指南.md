# Electron + Vue3 应用框架使用指南

## 1. 框架介绍

### 1.1 什么是 Electron + Vue3 框架？

这是一个基于 Electron 和 Vue3 技术栈的现代化桌面应用开发框架，专为小白开发者设计，让你能够快速构建跨平台的桌面应用程序。

- **Electron**：让你使用网页技术（HTML、CSS、JavaScript）开发桌面应用
- **Vue3**：现代化的前端框架，使界面开发更加简单直观
- **TypeScript**：提供类型安全，减少代码错误
- **Vite**：快速的构建工具，提升开发体验

### 1.2 框架能做什么？

- ✅ 创建跨平台桌面应用（Windows、macOS、Linux）
- ✅ 访问系统功能（文件系统、系统信息等）
- ✅ 多窗口管理和系统托盘
- ✅ 配置管理和持久化存储
- ✅ 现代化的用户界面
- ✅ 开发者工具和调试功能

## 2. 环境搭建

### 2.1 准备工作

在开始之前，你需要安装以下软件：

1. **Node.js**：访问 [Node.js 官网](https://nodejs.org/) 下载并安装最新的 LTS 版本
2. **代码编辑器**：推荐使用 [Visual Studio Code](https://code.visualstudio.com/)

### 2.2 安装框架

1. **克隆项目**：如果你有 Git，可以使用以下命令克隆项目
   ```bash
   git clone <项目地址>
   cd electron-vue3-demo
   ```

2. **安装依赖**：在项目目录中运行
   ```bash
   npm install
   ```

## 3. 快速开始

### 3.1 启动开发环境

最简单的方式是使用一体化启动命令：

```bash
npm run electron:dev
```

这个命令会：
- 构建应用
- 启动前端开发服务器
- 启动 Electron 应用
- 自动打开开发者工具

### 3.2 查看应用界面

应用启动后，你会看到一个现代化的界面，包含：
- 应用标题和操作按钮
- 框架信息展示
- 系统信息获取功能
- 开发者模式开关
- 配置面板入口

## 4. 核心功能详解

### 4.1 系统信息获取

点击「获取系统信息」按钮，应用会显示当前电脑的系统信息，包括：
- 操作系统版本
- CPU 信息
- 内存使用情况
- 磁盘信息

这是通过 Electron 的主进程访问系统 API 实现的。

### 4.2 开发者模式

点击「开发者模式」按钮，可以进入开发者模式，这里提供了：
- 后端通信测试工具
- 更多调试选项

在开发者模式下，你可以测试应用与后端的通信是否正常。

### 4.3 配置管理

点击「配置」按钮，会打开配置面板，你可以：
- 修改应用名称
- 调整窗口大小
- 更改主题设置
- 配置语言选项

所有配置都会自动保存，下次启动应用时会保持这些设置。

### 4.4 窗口管理

应用支持以下窗口操作：
- 最小化窗口
- 最大化/还原窗口
- 关闭窗口（默认会最小化到系统托盘）

### 4.5 系统托盘

当你关闭应用窗口时，应用会自动最小化到系统托盘：
- 点击托盘图标可以显示/隐藏应用窗口
- 右键点击托盘图标可以打开菜单
- 从菜单中可以完全退出应用

## 5. 项目结构详解

### 5.1 主要目录结构

```
electron-vue3-demo/
├── src/                 # 源代码目录
│   ├── main/            # 主进程代码
│   ├── renderer/        # 渲染进程代码（前端界面）
│   ├── preload/         # 预加载脚本
│   └── shared/          # 共享代码
├── assets/              # 静态资源
├── docments/            # 文档目录
├── package.json         # 项目配置
└── README.md            # 项目说明
```

### 5.2 主进程 vs 渲染进程

- **主进程**：运行在 Node.js 环境中，可以访问系统 API
- **渲染进程**：运行在 Chromium 浏览器环境中，负责界面渲染
- **预加载脚本**：连接主进程和渲染进程的桥梁

## 6. 开发新功能

### 6.1 添加新页面

1. 在 `src/renderer/components/` 目录中创建新的 Vue 组件
2. 在 `App.vue` 中导入并使用这个组件

### 6.2 添加新的系统功能

1. 在 `src/main/ipc/` 目录中创建新的 IPC 处理器
2. 在 `src/main/ipc-manager/ipc.manager.ts` 中注册这个处理器
3. 在 `src/preload/index.ts` 中暴露相应的 API
4. 在前端组件中使用 `window.electronAPI` 调用这个 API

### 6.3 示例：添加文件读写功能

**主进程**：
```typescript
// src/main/ipc/file.handler.ts
export class FileHandler extends BaseIpcHandler {
  async readFile(event: IpcMainInvokeEvent, filePath: string): Promise<string> {
    // 读取文件的逻辑
  }
}
```

**预加载脚本**：
```typescript
// src/preload/index.ts
contextBridge.exposeInMainWorld('electronAPI', {
  // 其他 API...
  readFile: (filePath: string) => ipcRenderer.invoke('file:read', filePath),
});
```

**前端使用**：
```typescript
// 在 Vue 组件中
const content = await window.electronAPI.readFile('path/to/file.txt');
console.log('文件内容:', content);
```

## 7. 构建和发布

### 7.1 构建应用

当你完成开发后，可以构建应用：

```bash
npm run build
```

### 7.2 打包应用

#### Windows 打包
```bash
npm run electron:build-win
```

这会生成一个可安装的 `.exe` 文件，位于 `dist-app/` 目录中。

#### 其他平台打包

修改 `package.json` 中的 `build` 配置，然后运行相应的打包命令。

## 8. 常见问题解答

### 8.1 应用无法启动

- **问题**：运行 `npm run electron:dev` 后应用没有启动
- **解决方法**：
  1. 检查端口 5173 是否被占用
  2. 确保 `npm install` 成功完成
  3. 查看终端中的错误信息

### 8.2 系统信息获取失败

- **问题**：点击「获取系统信息」按钮后没有反应
- **解决方法**：
  1. 检查应用是否有足够的系统权限
  2. 查看开发者工具中的控制台错误

### 8.3 配置不生效

- **问题**：修改配置后，下次启动应用配置没有保存
- **解决方法**：
  1. 确保应用正常退出（通过系统托盘的「退出」选项）
  2. 检查用户数据目录是否有写入权限

### 8.4 应用打包失败

- **问题**：运行打包命令后失败
- **解决方法**：
  1. 确保 `npm run build` 成功完成
  2. 检查 `package.json` 中的打包配置
  3. 查看终端中的错误信息

## 9. 进阶技巧

### 9.1 使用开发者工具

- **前端调试**：应用启动时会自动打开 Chrome DevTools，你可以在这里：
  - 查看和修改 HTML/CSS
  - 在 Console 中执行 JavaScript
  - 查看网络请求

- **主进程调试**：在终端中运行：
  ```bash
  electron . --inspect=9229
  ```
  然后在 Chrome 中访问 `chrome://inspect` 进行调试。

### 9.2 环境变量配置

在 `.env` 文件中可以配置应用的环境变量：

```
# 应用名称
APP_NAME=Electron Vue3 Framework

# 是否启用气球通知
BALLOON_NOTIFICATION_ENABLED=false
```

### 9.3 自定义图标

替换 `assets/` 目录中的图标文件：
- `icon.ico`：Windows 应用图标
- `icon.png`：其他平台的图标
